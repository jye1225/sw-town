# SM TOWN 기획

## 프로젝트 소개

**SM TOWN**은 "눈송이들의 취향이 만나는 곳"을 목표로 하는 대학생 소셜 플랫폼입니다.
취향이 맞는 친구를 찾고, 관심 있는 활동을 함께할 소모임에 참여하고, 함께한 순간을 기록할 수 있습니다.

- 과목: 웹프로그래밍 1분반 팀 프로젝트
- 사이트: <https://jye1225.github.io/sw-town/index.html>

## 대상 사용자

새로운 친구를 사귀고 싶거나, 취미를 함께할 사람을 찾는 대학생("눈송이")

## 주요 기능

| 기능 | 내용 | 화면 |
| --- | --- | --- |
| 친구 찾기 | 관심사가 비슷한 친구를 추천받고 프로필을 확인합니다. | `friend.html`, `friends.html`, `friend-profile.html` |
| 소모임 | 운동 · 독서 · 카페 · 문화 · 산책 카테고리별로 모임을 둘러보고 상세 정보를 확인합니다. | `group.html`, `group-detail.html` |
| 만남 기록 캘린더 | 친구와 만난 날을 사진과 메모로 달력에 기록합니다. | `calendar.html` |
| 마이페이지 | 내 프로필, 관심사, 주간 시간표, 참여 중인 소모임을 확인합니다. | `mypage.html`, `profile-edit.html`, `timetable.html` |
| 회원 | 로그인과 회원가입 화면을 제공합니다. | `login.html`, `signup.html` |

## 팀 구성

| 이름 | 담당 화면 |
| --- | --- |
| 해인 | 홈, 로그인, 회원가입, 만남 기록 캘린더, 공통 헤더 |
| 예은 | 소모임 목록 · 상세, 마이페이지, 프로필 수정 |
| 효원 | 친구 찾기 · 목록 · 프로필, 내 주간 시간표 |

## 디자인 규칙

공통 값은 `css/common.css`의 `:root`에 CSS 변수로 정의되어 있습니다.

### 색상

| 변수 | 값 | 용도 |
| --- | --- | --- |
| `--color-bg` | `#edeae5` | 페이지 배경 |
| `--color-surface` | `#f8f6f2` | 카드 · 입력칸 배경 |
| `--color-border` | `#dcd8d0` | 테두리 |
| `--color-text` | `#2f2f30` | 기본 글자 |
| `--color-text-sub` | `#635936` | 보조 글자 |
| `--color-brand` | `#946644` | 로고 · 강조 |
| `--color-active` | `#dbddbd` | 선택된 메뉴 · 탭 |
| `--color-primary` | `#35454e` | 주요 버튼 |

### 글꼴과 레이아웃

- 글꼴: 이서윤체(`IsYun`)
- 최대 너비: `1440px`
- 좌우 여백: 넓은 화면 `120px`, 좁은 화면에서는 화면 폭에 맞춰 최소 `20px`까지 줄어듦
- 모서리: `8px` · `10px` · `12px`
- 헤더 · 푸터: 모든 화면이 같은 구조를 사용합니다. 현재 화면 메뉴는 `--color-active` 배경으로 표시합니다.
- 반응형: 휴대폰 폭에서도 가로로 넘치지 않도록 화면별 CSS에 `@media`를 작성합니다.

## 개발 범위

### 중간 제출

- HTML과 CSS로 모든 화면의 정적 시안을 완성합니다.
- 버튼과 링크로 화면 간 이동이 가능하도록 연결합니다.

### 이후 개발 후보

현재 화면에 "화면 예시" 또는 "준비 중"으로 표시된 기능입니다.

- 친구 찾기 카드 넘기기 (O/X)와 친구 검색
- 캘린더 월 이동과 날짜 선택
- 소모임 참여 신청
- 프로필 저장과 사진 미리보기

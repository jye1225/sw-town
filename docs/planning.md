# SW Town 기획

웹프로그래밍 1분반 팀프로젝트의 기획 내용을 정리하는 문서입니다.

## 현재 개발 범위

- 초기 폴더 구조와 페이지별 기본 HTML, 공통 CSS를 준비합니다.
- 중간 제출까지 HTML과 CSS로 정적 화면을 제작합니다.
- JavaScript, 서버, 데이터베이스 연동은 중간 제출 범위에 포함하지 않습니다.

## 팀에서 작성할 내용

- 프로젝트 소개와 대상 사용자
- 페이지별 화면 구성
- 팀원 및 담당 페이지
- 공통 디자인 규칙
- 개발 일정

페이지 목록과 CSS 연결은 [사이트맵](sitemap.md)을 참고합니다.

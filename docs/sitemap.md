# SW Town 사이트맵

현재 홈에서 모든 페이지로 이동할 수 있으며, 각 페이지에는 홈 링크가 있습니다.
페이지 본문은 추후 작성할 기본 틀입니다.

| 화면 | HTML | 전용 CSS |
| --- | --- | --- |
| 홈 | `index.html` | `css/home.css` |
| 로그인 | `login.html` | `css/auth.css` |
| 회원가입 | `signup.html` | `css/auth.css` |
| 친구 | `friend.html` | `css/friend.css` |
| 친구 프로필 | `friend-profile.html` | `css/friend.css` |
| 친구 목록 | `friends.html` | `css/friend.css` |
| 그룹 | `group.html` | `css/group.css` |
| 그룹 상세 | `group-detail.html` | `css/group.css` |
| 마이페이지 | `mypage.html` | `css/profile.css` |
| 프로필 수정 | `profile-edit.html` | `css/profile.css` |
| 캘린더 | `calendar.html` | `css/calendar.css` |

모든 HTML은 `reset.css` → `common.css` → 전용 CSS 순서로 불러옵니다.
